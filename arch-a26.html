MuliOS A26.07.02S

The next MuliOS release is going Arch-first. A26.07.02S brings a real Archinstall-backed installer, a from-scratch Arch kernel build, cleaner profiles, and a brand new ISO-based OTA updater: MUpdate a1.0.4.

MULIOS-ARCH

Moving from an Arch-based build to a complete Arch pipeline.

Arch comes first

The A in MuliOS versioning refers to Arch. Arch support is becoming the primary direction, and the current MUpdate implementation is focused on Arch first.

Real Archinstall

Archinstall integration is being added to the Python installer, so setup uses the actual Archinstall backend instead of a fake or custom imitation.

Faster testing

The installer is being built toward supporting CTRL+H to skip the current step and move forward, useful for testing and automated installs.

OTA UPDATES

MUpdate a1.0.4 is now the real updater

REMOVED

mupdate a1.0.3

The old mupdate a1.0.3 has been removed at the MuliOS-Arch project level. It's fully replaced by MUpdate a1.0.4.

NEW

MUpdate a1.0.4

OTA updates are now designed around complete MuliOS ISOs rather than individual packages, making updates more predictable and easier to verify.

How an update runs

  1. Downloads the split ISO
  2. Reconstructs and verifies it
  3. Backs up user data
  4. Boots an update environment
  5. Installs the new MuliOS system
  6. Restores data and settings
  7. Reboots into the updated system
UNDER THE HOOD

Kernel work and project cleanup

Arch kernel, not Ubuntu

The kernels previously under C:\MuliOS\kernels\... were Ubuntu .deb kernels, not Arch kernels. Arch kernel work is now being done separately through the Arch/WSL environment using an Arch PKGBUILD.

Cleaner project structure

Profile directories containing airrootfs are being excluded from the normal tree and output, instead of being treated as part of the main build structure.

Beta build optimisation

Ongoing beta builds are bringing better overall optimisation ahead of the A26.07.02S release.
