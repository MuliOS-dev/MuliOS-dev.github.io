RELEASE OVERVIEW

Everything in the image
has a reason to be there.

A26.07.02S is the first stable release after internal testing. It is built on Arch Linux and ships KDE Plasma alongside MuliOS-specific tools.

01 / INSTALL

MuliOS Installer

A purpose-built Python/PySide6 installer for configuring the disk, selecting a profile and preparing the final system.

02 / RECOVERY

MuliRecovery

The recovery environment provides a dedicated place for system repair and restoration operations.

03 / UPDATE

MUpdate

MUpdate handles MuliOS update operations, including the project's OTA workflow for supported releases.

04 / MONITOR

Task Manager

A dedicated system monitor covering CPU, memory, GPU, disk, network and processes.
