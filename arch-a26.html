A26.07.02S · FIRST STABLE RELEASE

First stable.
Built as a system.

MuliOS A26.07.02S is the first stable MuliOS release based on Arch Linux. The release rebuilds the installation, update, recovery and system-management stack around MuliOS itself.

Download 1.8 GB ISO ↘Full GitHub release →

MuliRecovery 1.0.0

A dedicated Recovery OS environment for installation, updates, recovery and system maintenance. It is integrated with MUpdate so major system operations can happen outside the running installation.

MUpdate a1.0.5

The updater adds OTA system updates, split ISO downloads, user-data backup and restore, installer integration and Recovery OS integration.

Task Manager 1.0.0

A built-in task manager for system resources and running processes. The release notes credit archiveArther for the original application and jxstaboy for the extensive update and integration work.

MuliOS Installer

The installer was rebuilt from scratch and is purpose-built for MuliOS. A26.07.02S no longer relies on Archinstall or Calamares for installation.

KDE Plasma

The desktop ships with MuliOS-specific defaults, configuration changes and desktop customisation. The release also removes Firefox and Chinese/CJK fonts from the ISO to reduce its size.

Credits

The A26.07.02S release also includes the rebuilt MuliOS credits and contributor information.

Generic Kernel

The Generic Kernel is tuned for broad hardware compatibility, with improvements for NVIDIA GPUs, AMD CPUs and AMD GPUs. The profiling system was also simplified and modernised.

System requirements

The release notes state that minimum requirements match Arch Linux's requirements. Actual requirements vary with desktop configuration, applications and hardware.

CPU64-bit x86_64, 2 cores minimum · 4+ cores recommended
RAM2 GB minimum · 4 GB or more recommended
Storage20 GB free minimum · 40 GB or more recommended
GraphicsAny GPU supported by Linux · modern integrated or dedicated GPU recommended
FirmwareBIOS/UEFI · UEFI recommended
