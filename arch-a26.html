A26.07.02S · FIRST STABLE RELEASE

First stable.
Built as a system.

MuliOS A26.07.02S is the first stable MuliOS release based on Arch Linux. It brings the MuliOS installer, recovery environment, updater and system tools together in one release.

Download 1.8 GB ISOGitHub release

MuliRecovery 1.0.0

A dedicated Recovery OS for installation, updates, recovery and system maintenance.

MUpdate a1.0.5

System update tooling with OTA support, split ISO downloads, data backup and restore, and Recovery integration.

Task Manager 1.0.0

A lightweight application for monitoring system resources and running processes.

MuliOS Installer

Rebuilt from scratch as a purpose-built Python/PySide6 installer for MuliOS. The stable release does not rely on Archinstall or Calamares for installation.

KDE Plasma

MuliOS ships with KDE Plasma and MuliOS-specific desktop defaults and configuration.

Generic Kernel

The Generic Kernel targets broad hardware compatibility with improvements for NVIDIA GPUs, AMD CPUs and AMD GPUs.

System requirements

Actual requirements depend on the desktop, applications and hardware.

CPU64-bit x86_64, 2 cores minimum; 4+ cores recommended
RAM2 GB minimum; 4 GB or more recommended
Storage20 GB free minimum; 40 GB or more recommended
GraphicsLinux-supported GPU; modern integrated or dedicated GPU recommended
FirmwareBIOS/UEFI; UEFI recommended
