OM

En Linuxdistribution som anpassar sig.

MuliOS ger ett enkelt system som kan konfigureras efter olika sätt att använda en dator.

Valfrihet

Olika arbetsflöden och profiler utan att behöva ett helt annat operativsystem.

Prestanda

Ett fokuserat system med rimliga standardinställningar och hårdvaruanpassade förbättringar.

Anpassning

Skrivbordsinställningar, profiler och verktyg som låter systemet följa användaren.
