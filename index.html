01 / THE IDEA

Linux built around the person using it.

MuliOS is built around the idea that the operating system should adapt to different workflows rather than force every user into the same setup.

01

Choice

Different workflows should not require different operating systems.

02

Performance

A focused system that makes sensible use of the hardware underneath it.

03

Customization

Profiles and desktop configuration let MuliOS follow the way you work.

02 / THE SYSTEM

One release. Several rebuilt pieces.

A26.07.02S brings the desktop, installer, recovery environment, updater and system tools together.

01

MuliOS Installer

Rebuilt from scratch and purpose-built for MuliOS. The stable release no longer relies on Archinstall or Calamares for installation.

02

MuliRecovery 1.0.0

Dedicated Recovery OS for installation, updates, recovery and maintenance.

03

MUpdate a1.0.5

OTA updates, split ISO downloads, data backup and restore, and Recovery integration.

04

Task Manager 1.0.0

System resource and process monitoring with a lightweight interface.

05

KDE Plasma

MuliOS-specific defaults and desktop configuration for a consistent first boot.

06

Generic Kernel

Broad hardware compatibility and optimization for NVIDIA GPUs, AMD CPUs and AMD GPUs.
