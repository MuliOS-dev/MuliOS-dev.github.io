ABOUT

A Linux distribution designed to adapt.

MuliOS aims to give users a straightforward system that can be configured around different ways of using a computer.

Choice

Different workflows and profiles without needing a completely different operating system.

Performance

A focused system with sensible defaults and hardware-aware improvements.

Customization

Desktop settings, profiles and tools that let the system follow the user.

SYSTEM

What comes with MuliOS.

The stable release brings the main MuliOS components together in one system.

MuliOS InstallerPurpose-built Python/PySide6 installer for MuliOS.
MuliRecovery 1.0.0Recovery environment for installation, updates and maintenance.
MUpdate a1.0.5System update and OTA tooling with Recovery integration.
Task Manager 1.0.0Resource and process monitoring.
KDE PlasmaMuliOS desktop defaults and configuration.
Generic KernelBroad hardware compatibility with NVIDIA and AMD improvements.
