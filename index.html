01 / THE IDEA

Linux built around the person using it.

MuliOS is designed around the idea that the operating system should adapt to different workflows instead of forcing every user into the same setup.

01

Choice

Different workflows should not require different operating systems.

02

Performance

A focused system that makes sensible use of the hardware underneath it.

03

Customization

Profiles and desktop configuration let MuliOS follow the way you work.

02 / THE SYSTEM

Built for the whole machine.

A26.07.02S brings together the MuliOS desktop, installer, recovery environment, updater and system tools.

01

MuliOS Installer

Completely rebuilt from scratch and purpose-built for MuliOS. A26.07.02S no longer relies on Archinstall or Calamares for installation.

02

MuliRecovery

A dedicated Recovery OS for installation, updates, recovery and maintenance, integrated with MUpdate.

03

MUpdate a1.0.5

OTA support, split ISO downloads, user-data backup and restore, installer integration and Recovery OS integration.

04

Task Manager 1.0.0

A built-in system task manager with resource information and process monitoring.

05

KDE Plasma

MuliOS-specific KDE defaults, configuration and desktop customization for a coherent first boot.

06

Generic Kernel

Improved broad hardware compatibility and optimization for NVIDIA GPUs, AMD CPUs and AMD GPUs.
